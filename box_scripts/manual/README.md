# Redaction Box CV 3.6 Repository Manual

Open `index.html` for the canonical interactive manual. The printable companion is
`REDACTION_BOX_CV_REPOSITORY_MANUAL_3_6.pdf`.

The manual uses three real PDF page pairs and the exact detector version recorded in
`manual_manifest.json` (`3.6.0`). It explains the runtime
contract, proposal and rejection rules, component-versus-region distinction, and the
post-hoc Astra/v4 registration and target-coverage audit. It does not contain benchmark
labels or answer text as detector input.

All assets are local. No web server or network connection is required.
